CORE LOGIC

测试状态机

每只眼独立运行自适应阶梯式测试。从 4.6 开始，答对升级，连续三次答错结束。

4.6 起点 → 答对 → +0.1 → 答错1 → 同等级 → 答错2 → -0.1 → 答错3 → 结束

升级规则

每次答对 level +0.1，consecutiveWrong 归零。答对 5.3（探索上限）即结束该眼测试。最终成绩取 bestCorrectLevel，而非结束时所在等级。

降级规则

首次答错同等级换方向重试；连续第二次答错降 0.1 等级；连续第三次答错立即结束该眼测试。从未答对显示"低于 4.6／建议复测"。

随机性约束

使用确定性种子选择方向，方向不与上一题重复。E 视标不旋转——每个方向独立生成 5×5 网格，避免动画泄露答案。

RISK & TREND ANALYSIS

风险趋势分析

分左右眼独立分析，基线取此前 3 次有效测试中位数，采用谨慎的 0.2 阈值。

🟢

保持稳定 (stable)

本次结果与近期中位水平接近（下降 < 0.1），建议按相同条件持续记录。

🟡

轻微波动 (observe)

下降 0.1–0.2，建议休息后在相同光线、距离和设备条件下再次筛查。

🔴

建议复测 (retest)

下降 ≥ 0.2，建议尽快在相同条件复测；若持续下降，请咨询专业眼科。

⚪

继续积累 (insufficient)

至少需要三次历史结果才能判断变化趋势，当前数据不足以进行趋势分析。

📚 阈值依据

采用 0.2 的谨慎阈值，是因为 ETDRS 研究显示两行（0.2 logMAR）变化较能可靠地区分真实变化与重复测量误差。本项目的自适应算法不是 ETDRS，阈值只能作为非诊断性的产品启发式规则。

KEY FEATURES

核心功能

🎯 自适应 E 视标

从 4.6 起点，根据答对/答错自动升降等级。采用 5×5 网格确定性绘制，不使用字体或生成式图片。4.0–5.3 共 14 个等级、56 个 SVG 审计档案。

🎤 离线语音识别

使用 Picovoice Rhino Web (WASM)，在设备本地识别普通话"上、下、左、右、确认"命令。原始音频不持久化、不上传。键盘方向键始终可用作为兜底。

📏 屏幕校准

显示 50 mm 理论校准线（约 220.5 CSS px），用户用实体尺测量验证。偏差超过 1 mm 时不生成正式趋势，仅允许演示模式。

📊 趋势图表

自定义 SVG 折线图，右眼红色实线、左眼绿色虚线。支持最近 7 次（报告页）和最近 30 次（历史详情），按日期连续呈现。

🔐 本地优先

所有数据仅保存在 localStorage。演示数据和真实数据通过 ID 前缀分离。"登录"是本地档案入口，不创建云端账号。

✨ GSAP 动效

首页景深视差、页面过渡、E 视标入场/退场动画、倒计时脉冲。所有动效尊重 prefers-reduced-motion，优雅降级为简单淡入淡出。

🧪 完善测试

单元测试：尺寸公式、状态机、风险规则、数据持久化。E2E 测试：Playwright 使用本机 Chrome 完成首页与左右眼全流程。核心覆盖率门槛 80%。

♿ 可访问性

语义化 HTML、ARIA 标签、跳过导航链接、键盘全流程可操作、焦点可见指示器、减少动画偏好检测。

📦 一键启动

提供 macOS .command 文件双击启动：自动检测 Node.js、安装依赖、构建生产版本、启动预览服务器。

DATA MODEL

数据模型

localStorage 持久化，结构化类型定义，演示数据与真实数据完全隔离。

// AppData — localStorage["red-house-vision:v1"] { version: 1, profile: { nickname: "体验者", // 最多 24 字符，过滤 <>/\\ consentAcceptedAt: "2026-07-25T..." // 同意非医疗声明的时间 }, sessions: [ // 最多 120 条，按时间倒序 { id: "uuid-or-demo-N", // demo- 前缀 = 演示数据 completedAt: "ISO 8601", rightEye: 5.0, // 五分记录法，封顶 5.2 leftEye: 4.9, distanceMm: 2000, mode: "voice" | "keyboard" } ] }
🔒 隐私保护

昵称过滤 HTML 标签与路径字符。所有数据仅保存在当前浏览器 localStorage。清除浏览器数据会同时清除本地档案。提供 JSON 导出与一键清除功能。
